FAQ

Frequently Asked Questions
Does this work with MSFS 2020?

No, WhereToNext is built exclusively for MSFS 2024.

Where are my save files stored?

You'll find the wheretonext.db file stored in your AppData/Local/WhereToNext folder. You can edit this file in DBBrowser for SQLite.

Is this open source?

Not currently.

Do I need to purchase a license?

No, WhereToNext is free and always will be.
