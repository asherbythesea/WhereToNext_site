User Guide

Documentation

1. Run the .exe file as Administrator.

2. Open WhereToNext.

3. You will be prompted to install navigation data into your %LocalAppData% folder. (See the guide below if you need assistance.)

4. The onboarding screens will guide you through setting your name, starting plane, and starting location.

1. Launch MSFS 2024 and WhereToNext. WhereToNext will automatically connect to the simulator.

2. Go to the Hangar page to select your aircraft.

3. Select a job from the Jobs page.

4. On the Current Job page, you will see a Pre-Flight Briefing. You will need to go to Free Fly mode in MSFS 2024, select the correct plane (and variant), and starting location.

5. Start the simulator.

6. Open your EFB, set your flight plan, and configure your loadout. The Pre-Flight Breifing will tell you how many passengers and/or cargo is needed as well as an estimated fuel amount.

7. Once you meet the Plane, Location, and Weight requirements, you will be able to begin the flight. Press Begin Flight.

8. Optionally, you may paste in your route string from the EFB, Simbrief, or Little NavMap into the field below the map.

9. Fly to your destination, land, and set the parking brake to end the mission.

1. Launch MSFS 2024. You will need to wait until the buttons Accessibility and Start show up before you can create and load the scenery library.

2. Click Start to access the main menu of the simulator to avoid performance degradation caused by the movies.

3. In Little Navmap: you will create the database file little_navmap_msfs24.sqlite by going to the Scenery Library menu, and selecting Load Scenery Library, make sure "Microsoft Flight Simulator 2024" is selected in the dropdown menu, and then click the Load button.

4. After several minutes, the database will be created in %AppData%\Roaming\ABarthel\little_navmap_db. The approximate size of the database is 493MB.

MANUAL COPY: If for some reason WhereToNext isn't showing the dialog asking for the navigation database, you will now need to copy the database file to the WhereToNext application data directory. The location is %LocalAppData%\WhereToNext. Make sure you copy the little_navmap_msfs24.sqlite file; do not remame this file.
